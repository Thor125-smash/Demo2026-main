## Создание Ethernet-интерфейса

Перед созданием VLAN-интерфейсов необходимо создать базовый Ethernet-интерфейс, на котором будут терминироваться все VLAN.

### Шаг 1. Переход в раздел сетевых интерфейсов

Откройте браузер и перейдите по адресу **https://172.16.1.2:8443** (IP-адрес fw-cod).

Перейдите в **Сервисы → Сетевые интерфейсы → + Добавить → Ethernet**:

![Add Ethernet menu](../images/fw-cod_add_ethernet_menu.png)

### Шаг 2. Заполнение формы

Заполните форму **Добавление Ethernet-интерфейса**:

![Add Ethernet form](../images/fw-cod_add_ethernet_form.png)

Нажмите **Добавить**.

### Шаг 3. Результат

![Ethernet result](../images/fw-cod_ethernet_result.png)

## Создание VLAN-интерфейсов

### VLAN 100 (SRVs-COD)

#### Шаг 1. Добавление VLAN-интерфейса

Перейдите в **Сервисы → Сетевые интерфейсы → + Добавить → VLAN**:

![Add VLAN menu](../images/fw-cod_add_vlan_menu.png)

#### Шаг 2. Заполнение формы

Заполните форму **Добавление VLAN-интерфейса**:

![Add VLAN form](../images/fw-cod_add_vlan_form.png)

| Параметр | Значение |
|----------|----------|
| Название | srvs-cod |
| Роль | LAN |
| VCE | Системный контекст |
| Интерфейс | firewall1 |
| Тег VLAN | 100 |

Далее задайте статическую IP-конфигурацию:

| Параметр | Значение |
|----------|----------|
| Режим | Статическая конфигурация |
| IP-адрес | 192.168.10.254 |
| Маска | 255.255.255.0 (/24) |

Нажмите **Добавить**.

#### Шаг 3. Результат

![VLAN srv result](../images/fw-cod_vlan_srv_result.png)

✅ VLAN-интерфейс `srvs-cod` (VLAN 100) создан с IP-адресом `192.168.10.254/24`.

---

### Остальные VLAN

Аналогичным образом создайте интерфейсы для остальных VLAN:

| Название | VLAN | IP-адрес/маска | Интерфейс |
|----------|------|----------------|-----------|
| mgmt-cod | 300 | 192.168.30.254/24 | fw1-cod |
| cli | 400 | 192.168.40.254/24 | fw1-cod |
| voip | 500 | 192.168.50.254/24 | fw1-cod |

После создания всех VLAN-интерфейсов таблица должна выглядеть следующим образом:

| Ethernet | rtr-cod | eth0_01 | — | 172.16.1.2/30 |
| Ethernet | fw1-cod | eth1_da | — | — |
| VLAN | srv-cod | fw1-cod | 100 | 192.168.10.254/24 |
| VLAN | mgmt-cod | fw1-cod | 300 | 192.168.30.254/24 |
| VLAN | cli | fw1-cod | 400 | 192.168.40.254/24 |
| VLAN | voip | fw1-cod | 500 | 192.168.50.254/24 |

## Проверка доступа в Интернет

Для проверки корректности настройки маршрутизации можно использовать виртуальную машину sw1-cod.

### Временная настройка IP на sw1-cod

Используя средства `iproute2`, создайте тегированный подинтерфейс с IP-адресом из подсети VLAN 300:

```bash
# Создание VLAN-интерфейса
ip link add link ens19 name ens19.300 type vlan id 300

# Активация интерфейсов
ip link set dev ens19 up
ip link set dev ens19.300 up

# Назначение IP-адреса
ip addr add 192.168.30.1/24 dev ens19.300

# Добавление маршрута по умолчанию через fw-cod
ip route add 0.0.0.0/0 via 192.168.30.254
```

> 

### Проверка доступа в Интернет

```bash
ping -c3 77.88.8.8
```

![Ping Internet](../images/sw1-cod_ping_internet.png)

✅ Доступ в сеть Интернет с sw1-cod работает (3 received, 0% packet loss).

## Итоговая конфигурация

### fw-cod — Сетевые интерфейсы

| Интерфейс | Тип | VLAN | IP-адрес | Назначение |
|-----------|-----|------|----------|------------|
| rtr-cod | Ethernet | — | 172.16.1.2/30 | Связь с rtr-cod |
| fw1-cod | Ethernet | — | — | Trunk к sw1-cod |
| srv-cod | VLAN | 100 | 192.168.10.254/24 | Шлюз для серверов |
| mgmt-cod | VLAN | 300 | 192.168.30.254/24 | Шлюз для управления |
| cli | VLAN | 400 | 192.168.40.254/24 | Шлюз для клиентов |
| voip | VLAN | 500 | 192.168.50.254/24 | Шлюз для VoIP |

### switch1-cod — Временная конфигурация (для проверки)

| Параметр | Значение |
|----------|----------|
| Интерфейс | ens19.300 |
| IP-адрес | 192.168.30.1/24 |
| Шлюз | 192.168.30.254 (fw-cod) |
